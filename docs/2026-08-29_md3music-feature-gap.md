# md3Music 功能差距分析

## 分析边界

来源为 md3Music 公共仓库固定提交 `faf8a3fdcb16f905f9d0cae5ea69b4f41c70c55c` 的 README、模块目录及播放器状态实现。该仓库采用 AGPL-3.0；以下只记录功能事实和独立实现建议，不复制源码。

## 已在 GD Music Next 覆盖

- Material 3、自适应限宽、浅色/深色与动态配色
- 在线搜索、多音质解析、歌词、封面、后台 MediaSession
- 下载、下载队列、媒体标签、睡眠定时
- 播放队列、喜欢、自建歌单
- 顺序播放、列表循环、单曲循环、随机播放及模式持久化

## 尚未覆盖

### P0：基础音乐播放器能力

- 队列拖动排序（已提供按钮式上下移动）
- 听歌次数与累计时长统计（播放历史已完成）
- 本地音乐按专辑/歌手/文件夹分类浏览（MediaStore 扫描和播放已完成）
- 歌单内排序与批量管理（歌单改名已完成）

### P1：高价值播放体验

- 均衡器、淡入淡出/交叉淡化（倍速已完成）
- 歌曲信息页（码率、采样率、位深、声道、文件信息）
- 逐字歌词、歌词翻译/罗马音、歌词样式设置
- 音频焦点细化、拔耳机暂停和异常断点恢复
- 歌单/专辑/歌手详情、排行榜、每日推荐和相似歌曲

### P2：设备与生态扩展

- DLNA/AirPlay 投屏、MV 与画中画
- 桌面/锁屏/蓝牙歌词、桌面小组件、应用快捷方式
- USB DAC 独占输出与实时音乐频谱
- 云盘、账号同步、多账号、评论、关注歌手、听歌识曲
- 听书、私人 FM、场景音乐、频道及视频流等内容入口

## Evidence → Finding → Path

- Evidence：`PlayerStateRepository` 同时保存循环、随机、队列和位置；`PlayerProvider` 在应用层打乱队列，并强制底层 shuffle 关闭，避免多来源队列索引错位。
- Finding：GD Music Next 也应把“下一首选择”留在应用层；Media3 只负责当前单曲和单曲循环。
- Path：播放页按钮 → ViewModel 状态 → PlaybackPreferences；歌曲结束 → 应用层根据模式选择队列曲目 → 原有多音源解析 → Media3 播放。
